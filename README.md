# Aplikasi Renungan Harian

Aplikasi Renungan Harian adalah aplikasi Android modern yang dibangun menggunakan **Jetpack Compose** untuk membantu pengguna membaca renungan setiap hari secara praktis dan terstruktur. 

Aplikasi ini terhubung dengan backend API berbasis **Spring Boot** yang telah di-deploy di Railway sehingga data dapat diakses secara real-time dari mana saja.

Aplikasi ini dirancang dengan pendekatan **MVVM** untuk memastikan performa yang optimal, struktur kode yang rapi, serta kemudahan dalam pengembangan lebih lanjut. Pengguna dapat melihat renungan hari ini, membaca detail isi renungan, serta mengakses riwayat renungan sebelumnya melalui antarmuka yang sederhana dan nyaman digunakan.

Project ini merupakan implementasi dari pengembangan aplikasi mobile, mulai dari frontend Android, backend API, hingga deployment ke cloud.

---

## Fitur Utama

- **Renungan Harian Otomatis**  
  Menampilkan renungan sesuai tanggal secara dinamis

- **Detail Renungan**  
  Tampilan lengkap berisi ayat, isi renungan, dan penutup

- **List Renungan (Riwayat)**  
  Akses renungan hari-hari sebelumnya dengan urutan terbaru

- **Real-time Data**  
  Data diambil langsung dari API yang di-host di cloud

- **UI Modern (Jetpack Compose)**  
  Tampilan clean, responsif, dan mengikuti standar Android modern

- **Arsitektur MVVM**  
  Struktur code scalable dan mudah dikembangkan
